Das Carrera RL Projekt behandelt 2 Stufen eines Sim2Real Gedanken. Ein Carrera Hybrid Auto soll von einem RL-Agenten gesteuert werden. 

Im Notebook_prototyping.ipynb werden die Projektziele erklärt und es kann die erste Projektphase eingesehen und ausprobiert werden.

Stufe 1: 
RL-Ansätze 2D in Python erproben

Stufe 2:
Vielversprechende Ansätze in Isaac Sim realitätsnah umsetzen

Stufe 3: (mögliches Anschlussprojekt) 
Realversuch Agenten in die Realität überführen
